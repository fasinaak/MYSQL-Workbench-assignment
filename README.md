# Employee Database Management System – MySQL Assignment

## 📌 Project Overview

This project is a MySQL database assignment focused on creating and managing an Employee Database using appropriate SQL commands and constraints.

The database is designed to store information about departments, locations, and employees while maintaining data accuracy and integrity through SQL constraints.

## 🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL

## 🎯 Objectives

The main objectives of this assignment are:

- Create and manage an Employee database.
- Create tables using SQL.
- Apply appropriate constraints to maintain data integrity.
- Ensure unique identification of records.
- Prevent duplicate and NULL values where required.
- Use `AUTO_INCREMENT` for automatically generated identifiers.
- Apply `CHECK` constraints to restrict invalid values.
- Use default values where required.
